# 學區判定改用門牌比對表，不使用 point-in-polygon

Phase 1 的都市計畫分區判定是 point-in-polygon（座標比對圖資邊界），Phase 2 學區一開始也預設走同一條路，但實際查證後發現走不通。

台中市官方國小/國中學區資料是以「里」+「鄰」為單位的文字表，遇到里/鄰被兩間學校分吃時，再用街道/門牌區間文字條款細分（如「第20鄰建德街以南」）。查證確認**鄰本身沒有空間邊界**——同一棟建物、同一個座標，相鄰門牌可以被登記在不同鄰（鄰的分配是跟著門牌／戶籍走，不是跟著地理範圍走）。官方村里界圖（村里界圖.shp）只到里的層級，鄰以下沒有任何圖資存在。這代表就算疊圖疊到里的邊界，仍然無法處理鄰內部的街道/門牌細分條款，point-in-polygon 這條路在鄰的層級上本質上不可行。

決定：改用地址字串比對——查證確認台中市另外有一份每月更新、涵蓋全市每個門牌的 GIS 門牌號碼資料，本身就帶「里」「鄰」與座標欄位，等同一份現成的「門牌→里鄰」對照表。學區判定改為「地址→門牌表比對→里鄰→學區文字表比對」，不使用座標疊圖。詳見 `.scratch/school-district-lookup/research.md`。
