# Prompt Builder 匯出全部欄位，不做篩選

若 Prompt Builder 由 App 自行挑選要匯出哪些欄位（例如只挑「常見會問的」），那個篩選動作本身就是一種隱性判斷——等於替使用者決定了哪些資訊比較值得關注，與「零判斷責任」原則矛盾，即使呈現時完全不含形容詞。曾考慮讓使用者自行勾選要匯出的類別，技術上安全，但除了多一層 UI 工作量之外，並沒有解決「App 主動篩選」這個真正的風險——如果 App 本來就不做篩選，這層 UI 也沒有存在的必要。

決定：物件已蒐集到的六大類客觀資料，只要存在就全部輸出到 Prompt 字串中，不做欄位篩選、不做排序。此原則與 ADR-0005（不計算比較值）共同構成 Prompt Builder 的核心邊界：只組字串、不篩選、不計算。
