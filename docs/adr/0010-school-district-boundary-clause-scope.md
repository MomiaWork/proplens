# 學區分界條款解析範圍有限，無法解析時明確標示需人工確認

學區文字表裡，同一鄰被兩間學校分吃時的分界條款寫法不一致：多數是「XX街道以南/以北/以東/以西」這種單一街道分界，但也有「門牌單雙號區間」「多重巷弄組合」等更複雜的寫法。

若嘗試解析所有寫法，會大幅增加實作與維護成本，且愈複雜的條款愈難驗證解析正確性——一旦解析錯誤，會產生一個「看起來很確定但其實是錯的」學校名稱，這比明確的「無法判定」更危險：使用者會把它當成查證過的客觀事實（違反 CONTEXT.md「客觀事實」定義所要求的可獨立查證性）。

決定：學區比對邏輯只處理「整鄰對應單一學校」與「單一街道以南/以北/以東/以西」這兩種模式。遇到解析不出來的條款（多重巷弄門牌區間、罕見寫法組合等），回傳明確的 `needs-manual-review` 狀態，不猜測或退而求其次給一個可能錯誤的學校名稱。日後若發現大量地址落在無法解析的條款裡，再評估擴充解析規則，而不是在初版就追求覆蓋所有寫法。
