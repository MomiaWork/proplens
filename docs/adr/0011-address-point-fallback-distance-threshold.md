# 最近門牌點 fallback 設距離門檻，超過視為查無

門牌 CSV 是每月匯出的快照，新建物或新編訂門牌可能還沒被收錄；使用者輸入的地址格式也可能跟 CSV 的欄位切法對不上，導致精確比對失敗。此時退而求其次，用 Google Geocoding 給的座標去門牌 CSV 裡找最近的門牌點，繼承它的里/鄰。

若不設距離門檻，這個 fallback 在地址嚴重不符（例如比對邏輯本身有 bug，或地址其實在門牌資料涵蓋範圍邊緣）時，可能會抓到一個實際上相隔很遠、里鄰歸屬完全不相關的門牌點，產生一個看似有答案、實則錯誤的學區判定——與 ADR-0010 要避免的風險同一類。

決定：最近門牌點的距離門檻先訂為 200 公尺（保守值，可依實測資料分布調整），超過門檻視為「查無對應門牌」，回傳 `address-not-in-registry` 狀態，不繼承過遠門牌點的里/鄰。
