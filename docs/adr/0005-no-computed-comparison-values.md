# 開價與同分區均價分開呈現，App 不計算比較差額

物件資訊卡若讓 App 自行算出「物件開價 vs 同分區均價」的差額或百分比並顯示，即使運算本身是純數學，仍會傳遞出等同於價值判斷的訊息（暗示「這間偏貴／便宜」）。這正是《不動產估價師法》想避免的紅線——法律管的是有沒有給出估價／價值判斷意見，不是有沒有用形容詞；比較式數字只是判斷語句換了個包裝。

曾考慮附上免責聲明降低風險（呈現比較值＋「僅供參考」字樣），但免責聲明只降低風險、不消除責任：一旦被檢視，「App 自己算出的比較數字」比「使用者自己算」更難辯護為純客觀陳述。

決定：物件開價與同分區均價分開呈現為兩個獨立數字，App 不計算差額或百分比。使用者若要比較，透過 Prompt Builder 把兩個數字一併匯出，交由外部 AI 或自己判斷。此原則同樣適用於未來任何「把兩個以上客觀事實組合成單一評價信號」的呈現方式（例如排名、百分位）——不只限於價格。
