# 快取地址→里鄰比對結果，不快取里鄰→學校判定結果

延伸 ADR-0007 的邏輯：「地址→里鄰」是門牌登記的行政區劃事實，跟「地址→座標」的 geocoding 結果性質相同——同一棟房子的里鄰歸屬幾乎不會變，快取沒有過期風險，可以節省重複比對整份門牌 CSV 的成本。

「里鄰→學校」則跟「座標→都市計畫分區」判定性質相同：學區文字表每學年可能調整（依教育局公告），且沒有固定週期（開放資料集標註「不定期更新」）。若快取這一步的結果，會在學區調整後靜默過時，屬於 ADR-0004 要避免的同一類「靜默降級」風險。

決定：地址→里鄰比對結果進本地 SQLite 快取（比照 geocoding 快取的做法）；里鄰→學校判定完全不快取，每次都即時比對本地最新一份學區文字表檔案；學區文字表檔案本身另外用手動方式重新下載更新，不與查詢快取邏輯耦合（比照都市計畫圖資的做法）。
