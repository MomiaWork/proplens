# 以都市計畫分區作為有效交易的比較範圍，不用半徑或路段

物件資訊卡呈現價格背景資訊時，比較基準是**同分區有效交易**——物件座標所落入的都市計畫分區內的全部有效交易紀錄。曾考慮過的替代方案：(1) 半徑範圍（如物件座標 500 公尺內），(2) 同路段／同里的地址文字比對。兩者都被排除：半徑會額外引入距離計算，且可能跨越馬路對面不同分區或不同物件型態；路段/里比對依賴地址文字結構化解析，與「無官方REST API」的既有痛點疊加，且行政邊界不一定貼近實際生活圈。以都市計畫分區為範圍，剛好對應 Phase 1 唯一要驗證的技術能力（point-in-polygon），且同分區內使用性質通常一致，均價比較更有意義。日後可將半徑或路段作為輔助濾網疊加，但分區比對是不可省略的最小可行版本。
