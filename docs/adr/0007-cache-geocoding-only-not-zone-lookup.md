# 只快取地址→座標，不快取座標→分區判定結果

SQLite 本地快取用於避免重複呼叫有額度限制的 Geocoding API，快取對象限定為「地址→座標」——物件的地理位置是永久事實，快取沒有過期問題。

座標→都市計畫分區的 point-in-polygon 判定結果則不快取：經查證，台中市都市計畫圖(GIS)資料集的更新頻率是「不定期更新」（無固定週期），已快取的分區判定會在都市計畫變更（如通盤檢討）後靜默過時，與 ADR-0004 要避免的「靜默降級」屬於同一類風險。且分區判定本身是低成本的幾何運算，快取帶來的效益遠小於失準風險。

決定：分區判定每次即時對照本地儲存的最新一份都市計畫圖資檔案；圖資檔案本身另外用手動或排程方式重新下載更新，不與查詢快取邏輯耦合。
