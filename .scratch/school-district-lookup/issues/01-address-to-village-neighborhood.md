# 01 — 地址／座標 → 里鄰比對（門牌資料 + 快取）

**What to build:** 給定地址字串，比對台中市每月更新的門牌位置資料（本地儲存檔案），回傳所在的里、鄰。正規化地址（全形數字、「臺」/「台」異體字）後精確比對；比對失敗時，用座標找最近的門牌點（200 公尺內）繼承其里/鄰；仍找不到則回傳明確的「查無對應門牌」結果。比對結果（地址→里鄰）存入本地 SQLite 快取，同一地址第二次查詢不重複掃描門牌資料。

**Blocked by:** None — can start immediately（沿用 Phase 1 已驗證的 geocoding 邏輯取得座標，門牌比對本身不依賴新的外部 API）

**Status:** ready-for-agent

- [x] 給定精確比對到門牌資料的地址，回傳正確的里、鄰
- [x] 給定門牌資料裡查無精確比對的地址，用座標找最近門牌點（200 公尺內）並回傳其里、鄰
- [x] 給定最近門牌點也超過 200 公尺的地址，回傳明確的「查無對應門牌」結果，不回傳猜測的里鄰
- [x] 地址→里鄰的比對結果進快取，同一地址第二次查詢不重新掃描門牌資料
- [x] 地址正規化需處理全形/半形數字、「臺」/「台」異體字，確保與門牌資料的欄位格式一致
