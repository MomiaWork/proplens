# 05 — 物件查詢服務：同分區有效交易統計

**What to build:** 完整的「物件查詢」服務——輸入地址字串，回傳物件資訊卡（都市計畫分區 + 同分區有效交易均價與樣本數）。同分區有效交易筆數低於最低樣本門檻（預設5筆，可調整）時，改回傳原始交易清單並標示樣本不足。地址無法辨識或超出台中市範圍時，回傳對應的明確錯誤。這是 spec 定義的單一對外進入點。

**Blocked by:** 03 — 地址 → 都市計畫分區, 04 — 實價登錄 ETL：下載入庫有效交易紀錄

**Status:** ready-for-agent

- [ ] 給定落在交易量正常分區的地址，回傳正確分區名稱 + 同分區有效交易均價 + 樣本數
- [ ] 給定落在樣本數低於門檻分區的地址，回傳原始交易清單而非均價，並標示樣本不足
- [ ] 給定分區交界附近地址，回傳的分區判定與同分區有效交易統計互相一致
- [ ] 給定無法辨識或超出台中市範圍的地址，回傳對應的明確錯誤，不回傳空的或誤導性的物件資訊卡
- [ ] 服務對外不呈現任何自行計算的比較值、差額或百分比，僅呈現原始事實數字
