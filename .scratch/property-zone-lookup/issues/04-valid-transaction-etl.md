# 04 — 實價登錄 ETL：下載入庫有效交易紀錄

**What to build:** 定期下載實價登錄申報檔案，解析後過濾出 2021/7（實價登錄2.0上路）之後申報的交易紀錄，入庫為「有效交易紀錄」，可依門牌地址或所在都市計畫分區查詢。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 執行 ETL 後，資料庫內只有 2021/7 之後申報的交易紀錄，2021/7 前的區段化地址資料不會被匯入
- [ ] 每筆有效交易紀錄保留完整門牌地址、交易金額、交易日期
- [ ] ETL 可重複執行（例如每月 1/11/21 日附近重新下載）而不產生重複紀錄
- [ ] 有效交易紀錄可依地址查詢，供後續與都市計畫分區關聯使用
