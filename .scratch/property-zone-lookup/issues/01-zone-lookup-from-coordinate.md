# 01 — 都市計畫分區判定（point-in-polygon）

**What to build:** 給定一組座標，比對本地儲存的都市計畫圖資檔案（都市計畫圖(GIS)_WGS84），回傳該座標所在的都市計畫分區；座標不落在任何分區內時回傳明確的「查無分區」結果，而不是拋出例外或回傳空值。這是全案唯一未經驗證的技術風險，先用已知座標獨立驗證，不牽涉 geocoding 或實價登錄。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 給定已知落在某分區內部（非邊界）的座標，回傳正確的分區名稱
- [ ] 給定兩個分區交界附近的座標，回傳正確的分區判定（不誤判為相鄰分區）
- [ ] 給定不在任何都市計畫分區內的座標，回傳明確的「查無分區」結果
- [ ] 都市計畫圖資檔案可獨立於判定邏輯重新下載/更新，不需要修改程式碼
